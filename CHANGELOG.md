# Change log

## 12-month history fix

- Removed the 24-month public option; the dashboard now offers 6 or 12 months.
- Kept 12 months as the default selection.
- Anchored every neighbourhood to the latest market-wide data date so a 12-month view cannot silently end early.
- Fixed the graph axis to retain the full selected calendar window, leaving months with no source records blank.

## Website-focused release

- Rebuilt the public interface around the Inside The Valley cream, sand and forest palette.
- Replaced multi-select cluster comparison with a single-neighbourhood view.
- Added one-at-a-time choices for market, user goal, period, bedrooms, status/type and chart metric.
- Added buyer, seller, tenant and landlord explanations.
- Replaced the full transaction table and CSV download with eight concise recent-registration cards.
- Added recursive per-cluster PDF, CSV and Excel ingestion for bi-weekly updates.
- Added support for the principal Dubai Land Department Transactions and Rents CSV fields, including square-metre conversion.
- Retained persistent de-duplicated history through the included GitHub workflow.
- Documented the DXBinteract PDF workflow, official Claude MCP connector finding and current live-feed limitation.
